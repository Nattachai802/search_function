# 🚀 Email Full-Text Search Demo

ระบบค้นหาข้อความเต็มรูปแบบ (Full-Text Search) สำหรับฐานข้อมูลอีเมลขนาดใหญ่ใน MySQL สร้างด้วย Node.js และ Express.js

โปรเจกต์นี้สาธิตเทคนิคการค้นหาแบบ **Two-Phase Search** เพื่อให้ได้ผลลัพธ์ที่ทั้ง **รวดเร็ว** และ **แม่นยำ** โดยแก้ปัญหาคอขวดด้านประสิทธิภาพที่มักพบในการค้นหาข้อมูลจำนวนมาก

## ⚙️ หลักการทำงาน (How It Works)

จากการทดสอบเบื้องต้นพบว่า:
- **`LIKE '%...%'`**: ให้ผลลัพธ์แม่นยำ แต่ทำงานช้ามากบนข้อมูลขนาดใหญ่
- **`FULLTEXT` (Boolean Mode)**: ทำงานเร็วมาก แต่การจัดลำดับความเกี่ยวข้อง (Ranking) ยังไม่ดีพอ

เราจึงใช้แนวทาง **Two-Phase Search** เพื่อรวมข้อดีของทั้งสองแบบ:

1. **Preprocessing**
    -  ทำการ word tokenization สำหรับการแบ่งคำให้เรียบร้อยตามช่องว่าง
    - ค้นหาคำที่อยู่ในเครื่องมาย "" แล้วทำการดึงออกมาเพื่อกำหนดเป็นคำบังคับที่จะต้องค้นหาเจอ
    - แปลงรูปแบบให้เป็นมาตรฐาน เปลี่ยนเครื่องหมายต่างๆให้เป็นรูปแบบเดียวกัน และ ทำการตัดช่องว่างหน้าสุด หลังสุด

2.  **Phase 1: Candidate Retrieval (คัดกรองเบื้องต้น)**
    -   ใช้ `MATCH...AGAINST` ใน `BOOLEAN MODE` เพื่อค้นหา ID ของอีเมลทั้งหมดที่ "อาจจะ" เกี่ยวข้องกับคำค้นหาอย่างรวดเร็ว
    -   ขั้นตอนนี้จะกรองข้อมูลจากหลายล้านรายการให้เหลือเพียงกลุ่มเล็กๆ (เช่น 500 รายการ)

3.  **Phase 2: Re-ranking (จัดอันดับใหม่)**
    -   นำ ID ที่ได้จาก Phase 1 มาค้นหาซ้ำอีกครั้ง แต่ใช้ `MATCH...AGAINST` ใน `NATURAL LANGUAGE MODE`
    -   โหมดนี้จะคำนวณคะแนนความเกี่ยวข้อง (Relevance Score) ได้แม่นยำกว่ามาก ทำให้ผลลัพธ์ที่แสดงหน้าแรกๆ มีคุณภาพสูง

## 📋 Prerequisites

- Node.js (v16 หรือสูงกว่า)
- MySQL
- npm (มาพร้อมกับ Node.js)

## 🛠️ การติดตั้ง (Installation)

1.  **Clone a repository**
    ```bash
    git clone <your-repository-url>
    cd FindingBestAlgorithm
    ```

2.  **สร้าง `FULLTEXT` Index**

    รันคำสั่ง SQL นี้ในฐานข้อมูลของคุณ **เพียงครั้งเดียว** เพื่อสร้าง Index สำหรับการค้นหา (ขั้นตอนนี้อาจใช้เวลานานขึ้นอยู่กับขนาดข้อมูล)
    ```sql
    ALTER TABLE emailmessage
    ADD FULLTEXT INDEX ft_all_content (subject, bodyPreview, bodyHtml, bodyText);
    ```

3.  **ตั้งค่า Environment**

    สร้างไฟล์ `.env` ภายในโฟลเดอร์ `demo/` และใส่ข้อมูลการเชื่อมต่อฐานข้อมูลของคุณ:
    ```env
    # demo/.env
    DB_HOST=localhost
    DB_PORT=3306
    DB_USER=root
    DB_PASS=your_password
    DB_NAME=ai-dell
    PORT=3000
    ```

4.  **ติดตั้ง Dependencies**
    ```bash
    npm install
    ```

## ▶️ การใช้งาน (Usage)

1.  **รันเซิร์ฟเวอร์**
    ```bash
    npm run start
    ```

2.  **เปิดหน้าค้นหา**
    เข้าไปที่ http://localhost:3000/search.html ในเบราว์เซอร์ของคุณ
